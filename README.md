# Dart Mastery

This repository contains small, runnable Dart examples for the CS-314 Mobile Application Development Lab at UET Peshawar.

The examples progress from language fundamentals to exception handling, object-oriented programming, null safety, extensions, mixins, enums, and asynchronous programming. Each file is intentionally focused on one concept so students can run it, read it, and modify it.

## Running an example

Open a terminal in the repository root and run a file by quoting its path when needed:

```bash
dart run Dart-Mastery/01_dart_basics/01_variables.dart
```

For example, exception handling can be practiced with:

```bash
dart run Dart-Mastery/01_dart_basics/06_exception_handling.dart
```

All folders and Dart files use lowercase snake_case names so they work cleanly with terminal commands and scripts.

## Suggested order

1. `01_dart_basics`
2. `02_dart_data_types`
3. `03_control_flow`
4. `04_loops`
5. `05_functions`
6. `06_object_oriented_programming`
7. `07_null_safety`
8. `08_async_programming`

Exception handling is introduced in `01_dart_basics/06_exception_handling.dart` and is also practiced in Lab 02 through the Student Marks Analyzer.

These examples support the Week 02 and Week 03 lab tasks. Students should still complete the exercises and mini-projects in the course lab documents rather than copying the examples unchanged.
